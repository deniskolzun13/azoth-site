# AZOTH — сайт веб-разработчика-фрилансера

Одностраничник уровня creative development: тёмный чёрно-белый (монохром) киберпанк,
WebGL-фон («сетка-комната» + fbm-туманность), шейдерные глитч-переходы
между экранами, процедурные обложки проектов, прелоадер со сборкой
логотипа из частиц, калькулятор стоимости, RU/EN-версия.

**AZOTH — заглушка.** Настоящее имя, контакты и проекты меняются в двух файлах.

## Запуск

Нужен любой статический сервер (ES-модули не работают с file://):

```bash
cd сайттттт
python3 -m http.server 8123   # или: npm start
```

Открыть http://localhost:8123. **Интернет не нужен**: Three.js, GSAP, Lenis
и шрифты лежат локально в `vendor/`.

## Структура

```

js/data/i18n.js      — словарь RU/EN + применение к разметке
js/data/projects.js  — данные работ (5 демо-сайтов: demo/cover/shots,
                       task/solution/stack, role/duration/client)
js/data/calculator.js— цены и опции калькулятора (label: {ru, en})
js/core/shaders.js   — весь GLSL: фон, частицы, обложки
js/core/gl.js        — WebGL-сцена: фон, частицы, DPR, пауза, context lost
js/core/cards.js     — процедурные обложки (один рендерер на все карточки)
js/core/router.js    — страницы, глитч-переходы, колесо/стрелки/тач, Lenis
js/core/preloader.js, cursor.js
js/ui/works.js       — сетка/список работ, фильтры, сортировка по году,
                       живое превью в списке, клавиатурный доступ
js/ui/caseView.js    — кейс-вью: галерея из 6 кадров + лайтбокс,
                       задача/решение/стек, похожие проекты, фокус-ловушка
js/ui/calculator.js, contact.js, hud.js, menu.js, audio.js
js/main.js           — сборка всего + history API + метрика
tools/gen-case-pages.mjs — генератор SEO-страниц works/<slug>/ + sitemap
works/               — сгенерированные страницы кейсов (коммитятся)
worker/              — Cloudflare Worker для отправки заявок в Telegram
vendor/              — three.js, gsap, lenis, шрифты (woff2)
```

## Пять страниц

ГЛАВНАЯ → РАБОТЫ → УСЛУГИ (+3D-объект) → **КАЛЬКУЛЯТОР** → КОНТАКТ.

Калькулятор считает смету: сфера бизнеса (20 категорий — рестораны, клиники,
салоны, недвижимость, фитнес, образование, юристы, стройка, магазины, отели,
автосервис, логистика, мебель, event, клининг, ремонт техники, бухгалтерия,
детцентры, прокат, спа; у каждой своя база и свой блок допов) + универсальные
группы опций (задача — новый сайт / редизайн ×0.85, объём, дизайн, анимации
и 3D, CMS, контент,
интеграции, поддержка, срочность ×1–1.5).
Кнопка «Перенос в заявку» уносит конфигурацию прямо в форму на «Контакте».
**Цены-ориентиры меняются в [js/data/calculator.js](js/data/calculator.js).**

## Как управляется

- колесо / стрелки ↑↓ / PageUp-Down / клавиши 1–5 — переключение экранов
  (в конце прокручиваемой страницы — переход дальше);
- **Back/Forward браузера работают**: возвращают на прошлую страницу
  и закрывают/открывают кейс;
- бургер — полноэкранное меню, Esc закрывает всё;
- карточка работы — кейс-вью: клик мышью **или Tab + Enter**;
  ←/→ листают проекты, миниатюры галереи переключают кадры,
  «⤢ На весь экран» открывает лайтбокс (←/→ листают, Esc закрывает по слоям),
  «↗ Открыть сайт» ведёт на живое демо (demo/<slug>/),
  «⧉ Ссылка» копирует адрес кейса, Esc/Back закрывает;
- deep links: `#works`, `#about`, `#case-salt` (слаг кейса;
  старые числовые `#case-3` тоже работают) — открывают нужный экран/кейс;
- у каждого кейса есть SEO-страница `works/<slug>/` (title/description/OG/
  JSON-LD) с редиректом на кейс — генерируется `tools/gen-case-pages.mjs`;
- на «Работах»: фильтры по категориям, сортировка по году,
  переключатель сетка/список (в списке превью следует за курсором);
- на «Услугах» — интерактивный 3D-объект: тяни мышью, он вращается с инерцией;
- **EN/RU** — переключатель языка в HUD и в меню (запоминается);
- форма на «Контакте»: при настроенном `LEAD_API` шлёт заявку автоматически,
  иначе собирает текст — Telegram / почта / копирование;
- «ЗВУК» в правом нижнем углу — синтезированные звуки интерфейса
  (off по умолчанию, состояние запоминается);
- **H** — presentation mode: прячет весь HUD (Ctrl/Cmd+H не трогает);
- прелоадер можно пропустить кликом.

## Отправка заявок в Telegram

По умолчанию форма работает без бэкенда (текст заявки клиенту).
Чтобы заявки приходили ботом в Telegram — задеплой воркер из `worker/`
(инструкция в [worker/README.md](worker/README.md), ~5 минут, бесплатный
план Cloudflare) и впишите URL в `LEAD_API` в `js/config.js`.

## Аналитика

Впишите номер счётчика в `METRICA_ID` (js/config.js) — подключится
Яндекс.Метрика. Цели: `case_open`, `calc_to_form`, `lead_built`, `lead_sent`.

## Кастомизация

1. `js/config.js`: `BRAND`, `CONTACTS`, `AVAILABILITY`, `LEAD_API`, `METRICA_ID`.
2. `js/data/projects.js`: свои кейсы (title, year, cat/catLabel, tags, desc,
   task, solution, stack, role, duration, client, results — всё {ru,en};
   `demo` — путь к живому демо, `cover`/`shots` — скриншоты
   (demo/<slug>/shots/shot-N.jpg)). После правки данных перегенерируйте
   SEO-страницы: `node tools/gen-case-pages.mjs`.
3. **Демо-сайты** лежат в `demo/<slug>/` — каждый самостоятельный
   (свой CSS/JS/картинки, арт генерируется `python3 tools/gen-demo-art.py`).
3. **Тоже руками**: `<title>`, description, og-теги, JSON-LD в index.html;
   домен в `robots.txt`, `sitemap.xml`, `canonical`/`og:url`.
4. Цвета — в `:root` в `css/main.css`.
5. Логотип-частицы строится из текста `BRAND` автоматически.

## Доступность и устойчивость

- карточки кейсов доступны с клавиатуры (Tab/Enter), фокус-ловушка в кейс-вью
  с возвратом фокуса, aria-pressed на фильтрах/чипах;
- контраст мелкого текста поднят до WCAG-приемлемого;
- `-webkit-backdrop-filter` для iOS Safari;
- `prefers-reduced-motion` отключает глитчи/анимации;
- без WebGL сайт остаётся работоспособным: CSS-градиент фона + статичные
  2D-заглушки обложек;
- потеря WebGL-контекста в процессе (webglcontextlost) обрабатывается тостом
  и автовосстановлением;
- всё работает офлайн — CDN не используется.

## Производительность

- DPR ограничен (2 десктоп / 1.5 мобильный), меньше октав шума и частиц на
  мобильных, пауза рендера на скрытой вкладке.
